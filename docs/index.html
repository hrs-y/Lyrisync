Lyrisync
原始碼

v0.1 · Windows 10／11

為 Spotify 補全歌詞，並以優雅效果呈現。

Lyrisync 讀取正在播放的 Spotify 歌曲，從五個來源找出逐字同步的歌詞，讓每個字在唱到的那一刻亮起。

下載 Windows 版 在 GitHub 查看原始碼

免費・開源・Windows 10／11 x64

Moonlight DemoLyrisync

它能做什麼

Spotify 缺歌詞、只有逐行歌詞，或者你想要更好看的歌詞畫面時，打開 Lyrisync 就好。

逐字同步

同時向 AMLL TTML DB、QQ 音樂、網易雲音樂、酷狗音樂與 LRCLIB 搜尋，挑出時間最精細的版本並存在本機。

亮起與書寫

唱到的字依序亮起，或一個字一個字寫出來；背景隨專輯封面的顏色緩緩流動。

桌面歌詞

透明、置頂的兩行歌詞浮在所有視窗之上；鎖定後滑鼠可穿透，不打擾工作。

為每種文字挑字體

中文、日文、英文各有四種經典字體，包括思源宋體、霞鶩文楷、EB Garamond；每一行自動套用對應的字體。

連結 Spotify（選用）

以歌曲 ID 精準比對、預先載入下一首的歌詞、預覽待播清單，並在歌名旁按讚。

三種介面語言

繁體中文、English、日本語，預設跟隨系統語言。

開始使用

三個步驟，第三步可以跳過。

  1. 下載並安裝

    從 GitHub Releases 下載 Lyrisync_0.1.0_x64-setup.exe 並執行。安裝檔尚未數位簽章，Windows 可能顯示「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」即可。

  2. 在 Spotify 播放音樂

    打開 Spotify 桌面版播放任何一首歌，Lyrisync 會自動偵測並找出歌詞，不需要登入。

  3. 連結 Spotify（選用）

    在「設定 → Spotify」依步驟建立自己的開發者 App 並貼上 Client ID，就能使用精準比對、待播清單與按讚。依 Spotify 規定，開發者 App 的擁有者須為 Premium 會員。

說明

隱私

不需要註冊。歌詞快取與設定都留在你的電腦；連結 Spotify 時，登入資訊存在 Windows 認證管理員，只在本機使用。

歌詞著作權歸原作者所有。Lyrisync 僅在你的電腦上即時取得並快取，不會散布；與 Spotify、Apple 均無關聯。
